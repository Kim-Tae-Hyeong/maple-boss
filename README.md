# 보스 일정표 설치 방법

구조는 이렇게 동작해요.

- **구글 시트**: 일정이 저장되는 곳 (DB 역할)
- **Apps Script**: 시트를 읽고 쓰는 API. 수정할 때는 비밀번호를 확인해요.
- **GitHub Pages**: 여자친구와 내가 접속하는 URL

여자친구는 URL로 들어와서 보기만 하고, 나는 같은 URL에서 자물쇠 버튼을 눌러 비밀번호를 넣으면 편집할 수 있어요. 비밀번호는 한 번 넣으면 그 기기에 기억돼요.

---

## 1. 구글 시트와 Apps Script 준비 (약 5분)

1. [sheets.new](https://sheets.new) 에서 새 시트를 만들고 이름을 정해요. (예: 보스 일정)
2. 메뉴에서 **확장 프로그램 → Apps Script** 를 열어요.
3. 기본 코드를 전부 지우고 `Code.gs` 내용을 붙여넣어요.
4. 맨 위 `ADMIN_PASSWORD` 값을 내 비밀번호로 바꾸고 저장해요.
5. 위쪽 함수 선택 칸에서 `setup` 을 고르고 **실행** 을 눌러요.
   - 권한 요청 창이 뜨면 내 계정을 선택해요.
   - "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동** 을 누르고 허용해요. 내가 만든 스크립트라서 뜨는 정상적인 경고예요.
6. 시트로 돌아가 보면 `schedule` 탭과 헤더가 생겨 있어요.

## 2. 웹 앱으로 배포

1. Apps Script 오른쪽 위 **배포 → 새 배포** 를 눌러요.
2. 톱니바퀴에서 유형 **웹 앱** 을 선택해요.
3. 설정을 이렇게 맞춰요.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** 를 누르고 나오는 **웹 앱 URL** (`.../exec` 로 끝나는 주소)을 복사해요.

## 3. 페이지에 주소 연결

`index.html` 을 열어서 이 줄에 복사한 주소를 넣어요.

```js
const API_URL = 'https://script.google.com/macros/s/여기에-복사한-주소/exec';
```

## 4. GitHub Pages로 URL 만들기

1. [github.com](https://github.com) 에 로그인하고 **New repository** 를 만들어요.
   - 이름 예시: `boss` / 공개 설정은 **Public** (무료 Pages는 Public이어야 해요)
2. 저장소에서 **Add file → Upload files** 로 `index.html` 을 올리고 Commit 해요.
3. **Settings → Pages** 에서 Branch를 `main`, 폴더를 `/ (root)` 로 선택하고 Save 해요.
4. 1~2분 뒤 `https://내아이디.github.io/boss/` 주소가 생겨요. 이게 여자친구에게 보낼 URL이에요.

> 저장소가 공개여도 괜찮아요. 비밀번호는 Apps Script 안에만 있고 페이지 코드에는 없어요.

## 쓰는 법

- **보기**: URL에 접속하면 다음 보스까지 남은 시간과 날짜별 일정이 보여요. 1분마다 자동으로 새로고침돼요.
- **목록 / 달력**: 위쪽 탭으로 두 가지 보기를 바꿀 수 있어요. 마지막에 본 보기는 기기에 기억돼요.
  - 달력에서는 일정이 있는 날에 점이 찍혀요. (주황=예정, 초록=완료, 빨강=취소)
  - 날짜를 누르면 달력 아래에 그 날 일정이 펼쳐지고, 한 번 더 누르면 접혀요.
  - `‹` `›` 로 달을 넘기고 **오늘** 로 이번 달로 돌아와요.
- **편집**: 자물쇠 버튼 → 비밀번호 입력 → 아래 **일정 추가** 버튼이 생겨요.
- **달력에서 등록**: 달력에서 날짜를 고르면 버튼이 **이 날에 일정 추가** 로 바뀌고, 날짜가 미리 채워진 채로 입력창이 열려요.
- **한 파티에 보스 여러 마리**: 입력창에서 **+ 보스 추가** 로 늘리면 시트에는 보스마다 한 줄씩 저장되지만, 날짜·시간·캐릭터·파티원·메모·상태가 같으면 화면에서는 한 파티로 묶여서 보여요. 수정·복사·삭제도 파티 전체가 같이 움직여요. (수정창에서 보스 줄을 빼면 그 일정만 지워져요.)
- **다음 주로 복사**: 주간 보스처럼 반복되는 일정은 이 버튼으로 날짜만 7일 밀어서 바로 추가할 수 있어요. 파티에 묶인 보스가 여러 마리면 다 같이 복사돼요.
- **일정 변경**: 수정에서 시간을 바꾸거나 상태를 **취소** 로 바꾸면 여자친구 화면에도 줄이 그어져 보여요.
- **시트에서 직접 수정**: 급할 땐 시트에서 바로 고쳐도 반영돼요. 날짜는 `2026-09-12`, 시간은 `20:00` 형식으로 넣어 주세요. `id` 칸은 비워 두면 자동으로 채워져요.
- 휴대폰에서 URL을 연 뒤 **홈 화면에 추가** 하면 앱처럼 쓸 수 있어요.

## 문제 해결

- **Apps Script 코드를 고친 뒤 반영이 안 돼요**: 새 배포를 만들면 URL이 바뀌어요. 대신 **배포 → 배포 관리 → 연필 아이콘 → 버전: 새 버전 → 배포** 로 하면 기존 URL이 유지돼요.
- **"일정을 불러오지 못했어요"**: 배포 설정의 액세스 권한이 "모든 사용자"인지, `API_URL` 이 `/exec` 로 끝나는지 확인해요.
- **비밀번호를 바꾸고 싶어요**: `Code.gs` 의 `ADMIN_PASSWORD` 를 바꾼 뒤 위 방법으로 새 버전을 배포해요. 기존 기기에서는 자물쇠를 한 번 껐다가 새 비밀번호로 다시 켜요.
